灵犀拼音输入法 for Windows — 关于
========================================

灵犀拼音输入法 for Windows 是 Prisir(湃睿思) AI 出品的用户隐私保护软件,
纯本地运行,不强制联网,没有账号体系,支持用户百分百管理自己词库,
根据使用词频自动跳第一页显示,方便快捷录入。


隐私说明
--------

纯本地运行,不强制联网,支持用户百分百管理自己词库,
不收集遥测,不做行为分析,不设账号。

唯一的联网行为:每日一次匿名活跃信号(向我们的网站 GET 一个 updates.json,
不含任何身份/内容/使用数据,仅用于统计大致活跃数,与 PrisirAI 同口径)。
除此之外无任何后台联网。


使用条款
--------

本软件的轻量条款核心是「本地工具,自负其责」。
使用本输入法即视为同意:词库存本机,不外发。

完整法律文本见安装目录的 LICENSE.txt
(OI Enhancements Personal and Commercial Source License, OIE-PCS-1.0,
即 Prisir 项目在 GitHub 上各端共同使用的协议)。
